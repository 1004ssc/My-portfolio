01웨이퍼 결함 데이터셋 분석

81만 개 웨이퍼 원본 데이터를 직접 로드하고 (버전 호환성 문제 직접 해결), 데이터 구조를 완전히 분해해 9가지 결함 패턴의 분포와 형태를 정리했습니다.

라벨이 붙은 데이터는 전체의 21.3%뿐이며, 그중에서도 실제 결함 패턴은 3.1%에 불과 — 정상 웨이퍼가 압도적으로 많다는 것을 실측으로 확인했습니다.
결함 유형별 실제 웨이퍼맵 — 어두운 색이 불량 다이
데이터 구조 분석 전처리 matplotlib 시각화
02수율 추이 분석 & 이상탐지

웨이퍼맵의 양품/불량 다이를 직접 세어 811,457개 전체에서 실측 수율을 새로 계산하고, 로트 단위로 집계해 3-시그마 관리도(SPC) 방식으로 이상 로트를 자동 탐지했습니다.

26,741개 로트 중 319개(1.19%)가 관리한계를 벗어났고, 이 로트들이 무작위가 아니라 57개의 사건(연속 구간)으로 뭉쳐 나타난다는 것을 확인했습니다.
로트 순번에 따른 수율 추이 — 붉은 점이 3-시그마 이상탐지 로트
SPC 관리도 이상탐지 시계열 분석
03장비/챔버 상관관계 분석
방법론 시연: 실제 장비 이력 데이터가 공개되어 있지 않아, 실측 수율·이상탐지 결과에 가상의 챔버 이력을 결합한 시뮬레이션입니다. 목적은 특정 결론이 아니라 원인추적 방법론(챔버 매칭) 자체의 검증입니다.

실무에서 수율 이상 발생 시 표준적으로 쓰이는 '챔버 매칭' 절차를 재현해, 정답을 미리 심어둔 뒤 집계만으로 그 정답을 다시 찾아낼 수 있는지 검증했습니다.

무작위로 섞인 6개 챔버 중 의도적으로 표시해 둔 챔버가 평균 수율·이상탐지 비율 양쪽에서 동시에 다른 챔버 대비 뚜렷하게 낮게 나타나, 분석 방법의 유효성을 확인했습니다.
챔버별 평균 수율(좌)과 이상탐지 로트 비율(우)
근본원인분석(RCA) 그룹 집계 방법론 검증
04AI 웨이퍼 패턴 자동분류 모델

라벨링된 45,519개 웨이퍼로 결함 유형을 자동 분류하는 모델(Random Forest)을 직접 학습시키고, 클래스 불균형·이미지 크기 통일 등 실전 전처리 문제를 해결했습니다.

전체 정확도 79.9%를 달성했지만, 혼동행렬 분석으로 표본이 적은 패턴(Loc, Scratch)에서 정확도가 떨어진다는 한계를 스스로 진단하고 개선 방향까지 제시했습니다.
클래스별 예측 정확도를 보여주는 혼동행렬(Confusion Matrix)
