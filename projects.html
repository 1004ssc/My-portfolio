AI 데이터 분석 사이드 프로젝트
2026.08
배경 (Situation)

반도체 양산기술 직무를 준비하며, 실제 공정성 데이터를 다루는 감각을 구체적으로 보여줄 프로젝트가 필요했습니다.

과제 (Task)

공개된 대용량 웨이퍼맵 데이터셋(WM-811K, 811,457장)을 직접 로드·정제·분석해 결함 패턴을 분류하고 시각화하는 것.

수행 (Action)
  • Python 2 시절 pickle 포맷 호환 이슈를 직접 디버깅해 데이터 로드
  • 결함 패턴 9종 라벨 분포 집계 및 유형별 샘플 시각화
  • Claude Code로 인터랙티브 웹 리포트를 제작해 포트폴리오 사이트에 배포
성과 (Result)
  • 811,457장 중 172,950건 라벨 데이터 분류 완료
  • 결함 패턴 9종 시각화 리포트 제작·배포
  • Git 연동 자동 배포 파이프라인 구축

배경 (Situation)

이별·재회, 결혼 등 라이프스테이지별 사주 데이터 분석 서비스를 신규로 총괄하게 됐습니다.

과제 (Task)

광고 효율을 유지하면서 매출을 성장시키고, 성장이 꺾인 이후에는 사업 정리까지 책임지는 것.

수행 (Action)
  • Meta·X·틱톡 퍼포먼스 마케팅 직접 기획·운영
  • 프리랜서 계약 기반 팀 구조 설계로 고정비 대비 매출 효율 극대화
  • 광고 소재 A/B 테스트 및 채널별 ROAS 상시 모니터링
  • 성장 둔화 국면에서 데이터 기반으로 사업 정리 시점 판단
성과 (Result)
  • 월매출 192만 원 → 2,753만 원으로 성장(피크), 광고 효율 ROAS 2.06–2.23배 유지
  • 누적 사용자 1만 명 이상 확보
  • 사업 정리 및 일부 서비스 매각 완료

배경 (Situation)

한양대 혁신창업스쿨에서 시작해 AI 기반 가상 피팅 서비스를 공동창업했습니다.

과제 (Task)

정부지원사업 확보, 팀 빌딩, 제품 개발 및 글로벌 시장 검증까지 총괄하는 것.

수행 (Action)
  • 예비창업패키지 지원사업 선정, 사업계획서 작성 및 정부지원금 집행
  • 정규직원 5명 채용 및 팀 운영
  • 지식재산권 6건(특허 2건·상표 4건) 출원
  • 실리콘밸리 파견 프로그램 참가로 글로벌 시장 검증 (2023.01)
성과 (Result)
  • 정부지원금 5,100만 원 확보·집행, 앱스토어 정식 출시
  • 창업클럽 경진대회 장려상 수상
  • 이미지 합성 기술의 상용화 한계를 확인하고 신속히 사업 종료 판단
